# MusicW - Music Playlist Manager
## Live Website

https://musicw.onrender.com

## Features

- View music playlist
- User registration
- User login
- User logout
- GitHub OAuth login
- Add songs
- Edit songs
- Delete songs
- MongoDB database storage
- Protected song management features
- Responsive navigation
- Deployed using Render

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Handlebars
- Passport.js
- Passport Local Mongoose
- Passport GitHub2
- Express Session
- Connect Flash
- Bootstrap
- HTML
- CSS
- JavaScript
- GitHub
- Render
